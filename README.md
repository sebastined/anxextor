# anxextor

Web security checks for everyone. Enter a site, click scan, and get a simple score with clear next steps.

**TLDR**: Visit https://anxextor.sebastine.ng, scan any site, and share the results with your team.

## What it does

- Runs fast checks on a website for security headers, TLS, redirects, and DNS.
- Produces a score and a plain-language summary.
- Shows remediation steps you can follow immediately.
- Supports scanning multiple sites at once.
- Supports wildcard input like `*.abc.xyz` by scanning the base domain.

## Who it is for

- Founders and product owners who need a quick security snapshot.
- Developers who want actionable fixes.
- Compliance teams who need consistent evidence and summaries.

## What you get

- Clear score and grade
- Findings list with severity
- Remediation checklist
- CSV and PDF export for sharing

## Planned user features

- Sign in with Google or GitHub
- Personal scan history
- Professional report for technical and non-technical audiences
- Compliance-ready summaries
